Execute the milestones in Section 20 in order. After each milestone, run the relevant tests and capture visual evidence. Maintain an implementation checklist against Section 19.7. Finish with a clean build, test summary, QA screenshots and short gameplay recordings. Public deployment requires actual infrastructure access. If unavailable, deliver and verify Docker deployment locally, and do not invent a URL.

All in-game language must be polished US English. Do not use generic promotional filler, em-dash interruptions, or double-hyphen punctuation in player copy.
